# .GitLab

GitLab-specific configuration files for the homelab-monitoring repository.

## Files

| File | Description |
|------|-------------|
| `CODEOWNERS` | Defines file ownership for merge request approvals. Shared configs (`.pre-commit-config.yaml`, `.yamllint`, templates) are owned by `homelab-ci-templates` and auto-synced -- do not modify them here. |
| `merge_request_templates/Default.md` | Default merge request template. Provides a structured format with summary, change type checkboxes, testing checklist, and related issues section. |
