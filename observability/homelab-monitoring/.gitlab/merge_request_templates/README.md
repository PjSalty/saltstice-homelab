# merge_request_templates

GitLab merge request templates for the homelab-monitoring repository. These templates are auto-synced from `homelab-ci-templates` and should not be modified directly.

## Files

| File | Description |
|------|-------------|
| `Default.md` | Default merge request template. Provides structured sections for summary, changes list, change type (bug fix, feature, breaking change, etc.), checklist (style, self-review, docs, no secrets, testing), testing description, and related issues. |
